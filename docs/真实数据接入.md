# 测试数据 / 真实数据分层接入

## 1. 数据分类

| 类型 | 产生方式 | `sourceType` | `is_test` | 平台展示 |
|---|---|---|---|---|
| 测试数据 | 平台自动执行 Golden/用例 | `ai_test` | true | 测试数据 |
| 真实数据·人工 | 人从平台点“人工体验”，在尚品汇 `/ai?test=human` 对话 | `human_manual` | true | 真实数据 |
| 真实数据·生产 | 尚品汇线上真实用户 | `production` | false | 真实数据 |

测试数据只统计测试运行；真实数据不参与通过率/Judge 均分，避免两套指标混算。

## 2. 测试流量隔离

平台 `shangpin` 适配器对登录后的建会话/发消息请求统一带：

```text
X-Agent-Test: ai|human
X-Agent-Test-Run-Id: <平台 runId 或 human-时间戳>
```

尚品汇 `ChatController.createSession` 读取后写入：

- `customerservice.chat_session.is_test`
- `customerservice.chat_session.test_source`
- `customerservice.chat_session.test_run_id`
- `customerservice.agent_run.is_test/test_source/test_run_id`

测试会话强制独立，不复用真实进行中会话；AI 自动测试的 webhook 默认不推送，由平台自己记录。

## 3. 生产真实数据 webhook

尚品汇 `PlatformWebhookService` 使用 outbox：

- 业务事务写 `customerservice.platform_outbox`
- 定时任务每 5 秒投递，失败指数退避，最多 8 次
- HMAC-SHA256 签名：`hex(hmac_sha256(secret, raw_body + "\n" + timestamp))`
- 请求头：`X-Shang-Signature`、`X-Shang-Timestamp`、`X-Shang-Event-Id`

平台接收：

```text
POST /api/v1/agent-test/ingest/shangpin?pid=ecommerce&targetId=AT-...
```

事件示例：

```json
{
  "eventId": "evt-...",
  "eventType": "run.finished",
  "externalSessionId": "123",
  "externalRunId": "456",
  "externalMessageId": "789",
  "isTest": false,
  "testSource": "",
  "clientType": "h5",
  "userText": "推荐一个手机",
  "answer": "为您找到...",
  "cards": [],
  "sources": ["vector:104"],
  "tools": ["searchProducts"],
  "intent": "PRESALE",
  "agent": "SHOPPING_GUIDE",
  "status": "OK",
  "latencyMs": 1200,
  "tokens": 100
}
```

平台按 `(source,eventId)` 幂等，按 `(project,target,sourceType,externalSessionId)` 归并会话，按 `externalRunId` 幂等更新运行。

## 4. 环境变量

平台 `/etc/ai-test-platform.env`：

```bash
INGEST_WEBHOOK_SECRET=<与尚品汇一致的随机密钥>
INGEST_DEFAULT_PROJECT=ecommerce
INGEST_DEFAULT_TARGET=AT-CA66D70EFB
```

尚品汇 `/opt/shang-pivot/.env` 或 systemd 环境：

```bash
PLATFORM_WEBHOOK_ENABLED=true
PLATFORM_WEBHOOK_URL=https://agent.bettery.cn/api/v1/agent-test/ingest/shangpin?pid=ecommerce&targetId=AT-CA66D70EFB
PLATFORM_WEBHOOK_SECRET=<同上>
PLATFORM_WEBHOOK_INCLUDE_TEST=false
AGENT_CART_CONFIRM_AMOUNT_THRESHOLD=500
```

## 6. 页面

平台：`项目 → 任务与报告 → Agent 测试`

- `测试数据`：测试用例、运行控制台、Trace、修复工作台、经验文档
- `真实数据`：人工测试/生产会话列表、详情、人工判定、转测试用例
- 目标行的“人工体验”会打开 `https://shang.bettery.cn/ai?test=human`，会话记录为 `human_manual`

## 7. 保留与脱敏

- 平台侧手机号/身份证/邮箱二次脱敏，`pii_masked=true`
- 真实会话默认保留 30 天，可调用 `POST /api/v1/agent-test/maintenance/retention?days=30` 清理
