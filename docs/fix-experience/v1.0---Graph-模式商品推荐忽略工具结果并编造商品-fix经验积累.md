## 根因分析

graph answer 节点没有把工具返回的 ProductHit 卡片注入最终回答上下文，或 Prompt 未强制“只能引用 facts 中商品”；同时卡片事件未透传。

## 修复方案

在 AgentGraphOrchestrator 的 answer 节点传入 cards 与 facts，并在 Prompt 中增加“只能引用给定商品，禁止编造型号”；对最终答案做商品实体与 cards 的一致性校验；补充 graph 导购回归用例。
