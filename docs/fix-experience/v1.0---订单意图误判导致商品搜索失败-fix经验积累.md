## 根因分析

意图路由 Prompt 缺少商品搜索样例，通用动词“找”被订单意图抢占；低置信度时兜底到 OrderAgent。

## 修复方案

补充商品搜索 few-shot；将 OrderAgent 收敛为必须命中订单语境；低置信度改为反问澄清。
