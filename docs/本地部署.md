# 本地部署

## 1. 依赖

- Python 3.12、pnpm 11、PostgreSQL 17（含 pgvector）
- MinIO（可选，商品图/附件；脚本会尝试 `.local/minio/minio.exe`）
- RabbitMQ（可选，尚品汇订单事件；Windows 服务 `RabbitMQ`）
- Java 21（仅本地尚品汇 graph 需要）

## 2. 首次准备

```bash
cd backend
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt
cp .env.example .env
# 编辑 .env：DATABASE_URL、APP_SECRET、SEED_ADMIN_PASSWORD、JUDGE_* 等
.venv/Scripts/python -m alembic upgrade head

cd ..
pnpm install
```

`backend/.env` 已被 `.gitignore` 忽略，不要提交。

## 3. 一键启动

```bash
# 可选：指定尚品汇本地仓库，启动 graph 后端
export SHANGPIVOT_HOME=/d/shang-pivot-automation-ls_v2_withxdist

bash scripts/deploy_local.sh
```

脚本会启动/检查：

| 服务 | 端口 |
|---|---|
| PostgreSQL | 55432 |
| MinIO | 9000 / 9001 |
| RabbitMQ | 5672 |
| 平台后端 | 8000 |
| Mock Agent | 8088 |
| 平台前端 | 8443 |
| 尚品汇 graph（可选） | 8086 |

## 4. 验证

```bash
curl http://127.0.0.1:8000/healthz
curl http://127.0.0.1:8088/health
curl http://127.0.0.1:9000/minio/health/live
curl http://127.0.0.1:8443/
```

平台入口：`http://127.0.0.1:8443/project/ecommerce/tasks/agent-test`

账号密码见 `backend/.env` 的 `SEED_ADMIN_PASSWORD`。

## 5. 停止

```bash
# 只停应用进程，不停 PostgreSQL/MinIO
bash scripts/stop_local.sh

# 同时停 PostgreSQL
bash scripts/stop_local.sh --all
```

RabbitMQ 是 Windows 服务，如需停止：

```bash
sc stop RabbitMQ
```

## 6. 更新

```bash
git pull
cd backend && .venv/Scripts/python -m alembic upgrade head
cd .. && pnpm install && pnpm build
bash scripts/deploy_local.sh
```

## 7. 注意

- `scripts/deploy_local.sh` 使用本地开发默认 MinIO 凭据（minioadmin/minioadmin），生产必须替换。
- 前端默认使用 `pnpm preview` 托管构建产物；如需开发热更新，改用 `pnpm dev --host 127.0.0.1`。
- MinIO 是后台进程，不是 Windows 服务；机器重启后需重新执行部署脚本或单独启动。
- RabbitMQ 默认 `guest/guest` 只适合本机，生产必须改账号密码。
