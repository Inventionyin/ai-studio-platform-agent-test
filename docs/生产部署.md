# 生产部署（尚品汇同机，agent.bettery.cn / /agent-test/）

## 拓扑

推荐入口（独立子域名，根路径）：

```text
https://agent.bettery.cn/
  → nginx 443 (agent.bettery.cn)
    ├─ /                → /opt/ai-test-platform/current/frontend-agent
    └─ /api/            → 127.0.0.1:8000/api/

https://shang.bettery.cn/agent-test/
  → nginx 443 (shang.bettery.cn)
    ├─ /agent-test/     → /opt/ai-test-platform/current/frontend
    └─ /agent-test/api/ → 127.0.0.1:8000/api/

/opt/ai-test-platform/current/backend  ← FastAPI + venv
/etc/ai-test-platform.env              ← 生产环境变量（root 600）
/etc/systemd/system/ai-test-platform.service
/opt/ai-test-platform/data/uploads
/opt/ai-test-platform/data/fix-experience
```

数据库：PostgreSQL `ai_test_platform`，独立用户 `ai_test`，不与尚品汇 `shang` 库共用。

## 构建前端

独立子域名（根路径）：

```bash
cmd //c "set FIGMA_PUBLIC_URL=&& set VITE_API_BASE_URL=/api/v1&& pnpm build"
```

要求 `dist/index.html` 中资源路径为 `/assets/...`，上传到
`/opt/ai-test-platform/current/frontend-agent`。

兼容旧入口（子路径）：

```bash
cmd //c "set FIGMA_PUBLIC_URL=/agent-test&& set VITE_API_BASE_URL=/agent-test/api/v1&& pnpm build"
```

要求 `dist/index.html` 中资源路径为 `/agent-test/assets/...`。

## 服务器配置

- 子域名 nginx：`/etc/nginx/sites-available/agent.bettery.cn`
  - TLS：`/etc/letsencrypt/live/agent.bettery.cn/fullchain.pem`
  - webroot 续期：`/var/www/acme-webroot`
- 旧子路径 nginx snippet：`/etc/nginx/snippets/ai-test-platform.conf`
- systemd：`ai-test-platform.service`
- 环境文件：`/etc/ai-test-platform.env`
  - `FRONTEND_URL=https://agent.bettery.cn`
  - `COOKIE_PATH=/`（同时兼容根域名与 `/agent-test/`）
  - `COOKIE_SECURE=true`
